# Anji's Office Adventure 🐾

A small, free browser platform game. Help Anji collect animals and miniatures while dodging flying emails!

## Play
- Desktop: **A/D** or **←/→** to move, **Space**, **W** or **↑** to jump.
- Mobile: use the on-screen buttons.
- **R** restarts the game.
- Collect **5 animals** and **3 miniatures**, then reach the meeting room.
- Animals restore energy. Miniatures restore energy. Truffles the black dog restores extra energy and gives a temporary email shield. Emails drain energy and slow Anji down.

## Publish with GitHub Pages
1. Sign in at https://github.com and click **New repository**.
2. Name it `anji-office-adventure`, choose **Public**, and create it.
3. Click **Add file → Upload files**. Upload `index.html`, `style.css`, and `game.js` from this folder **to the repository root**. Commit the changes.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
5. After deployment, visit `https://YOUR-USERNAME.github.io/anji-office-adventure/`.

To update the game, upload/commit updated files to the same repository. GitHub Pages will redeploy.

## Notes
This first playable version uses self-contained canvas-drawn cartoon graphics and emoji, not real photographs. It does not require a server or external libraries. All in-game text is in English.
