# Anji’s Office Adventure — Version 6.0

English-language side-scrolling office platform game. Anji wears a pink dress and meets **8 animals**, including Truffles, a cat, a rabbit, a cockatoo and a new fluffy **white poodle**. Animals gently pace on their supporting floor or desk platforms. Collect coffee for energy; avoid flying emails, invoices, budget alerts and overdue payments. No miniatures.

## How to play
Open `index.html` in a browser. Move with Left/Right or A/D, jump with Space/Up/W, restart with R. On mobile, use the on-screen controls.

## Publish to GitHub Pages
Extract the ZIP and upload `index.html`, `style.css`, `game.js` and the **entire `assets` folder** to the root of your GitHub repository. Commit changes. In repository Settings → Pages, deploy from `main` / `(root)`. Refresh after deployment.

The new poodle is `assets/white-poodle.png`; an editable SVG source is also provided. Other illustrated character assets from v5 are preserved.
