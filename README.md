# Anji's Office Adventure — Version 2.0

A lighthearted, English-language browser platformer. Anji loves animals, miniature collectibles, and coffee. Emails, unpaid invoices, budget alerts and overdue payments drain her energy.

## Play
Open `index.html` in a modern browser. No installation, external assets, accounts or build steps required.

**Desktop:** Arrow Left/Right or A/D to move; Space/Up/W to jump; R to restart.

**Mobile:** Use the on-screen directional and jump buttons.

## Gameplay
- Find **7 animals** to restore energy and unlock a super jump.
- Find **Truffles**, Anji's fluffy black dog, for a temporary shield and a large energy bonus.
- Collect **8 unique miniatures**: house, dinosaur, car, castle, plant, books, desk and robot.
- Pick up **coffee** to recover energy and move faster for a short time.
- Avoid flying **emails**, **unpaid invoices**, **budget alerts** and **overdue payments**. These reduce energy and temporarily slow Anji.
- Reach the meeting room after collecting all animals and miniatures.

## Publish with GitHub Pages
1. Create a **public** GitHub repository (e.g. `anji-office-adventure`).
2. Upload `index.html`, `style.css`, `game.js` and this `README.md` to the **root** of the repository. Do not upload the enclosing folder instead.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then click **Save**.
5. Wait for deployment. Visit `https://YOUR-USERNAME.github.io/anji-office-adventure/`.

## Update an existing GitHub Pages site
Replace the old `index.html`, `style.css`, and `game.js` in the same repository with these files and commit the changes. If you still see the old version, refresh without cache or use a private/incognito window.

The illustrations are drawn in the game's canvas using code. The earlier detailed concept artwork is not used as an in-game sprite sheet; this version improves the built-in artwork but is not identical to that concept image.
